# AGENTS.md

## ui-sdk

This project uses `@ui-sdk/react` + `@ui-sdk/core` (exact-pinned; the beta
API can move). Before using ui-sdk, follow the ui-sdk skill if it's
installed, and read `node_modules/@ui-sdk/react/docs/llms.txt`. To build a
new component, also search `node_modules/@ui-sdk/react/docs/core.md` by
heading, and read `rendering.md` next to it.
